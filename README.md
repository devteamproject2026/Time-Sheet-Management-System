WorkPlus is an enterprise workforce management platform designed to streamline task allocation, project tracking, and timesheet management through a secure, centralized application. The platform provides role-based access for Administrator, HR Head, Manager, and Employee, enabling secure authentication, user management, project and task assignment, timesheet submission, approval workflows, progress tracking, reporting, and an AI-powered virtual assistant for real-time guidance. The frontend is built with React.js, while the backend leverages Spring Boot, RESTful APIs, Spring Security, JWT Authentication, and MySQL for efficient data management. The system follows a microservices architecture, ensuring scalability, modularity, and maintainability. A parallel backend is developed using ASP.NET Core Web API with Entity Framework Core, integrated with the same React frontend to demonstrate cross-platform capability. Git and GitHub are used for version control.
